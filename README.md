# CryptoLearn

CryptoLearn is a Next.js learning platform concept for understanding crypto from beginner to advanced: blockchain, Bitcoin, trading, DeFi, tokenomics, wallets, security and on-chain analysis.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
